The Woodpecker Training Method

A specialized form of spaced repetition designed by GM Axel Smith and IM Hans Tikkanen to burn chess patterns into your subconscious.

1

Generate & Lock a Set

Create a custom set of puzzles based on your target theme and Elo rating bracket. The set remains static throughout your entire training.

2

The 4-Cycle Repetition

Solve the exact same set over 4 consecutive cycles. Latent memory will allow you to solve them faster and more accurately each time.

3

Halve the Target Time

With each new cycle, aim to complete the set in exactly half the time of the previous cycle (e.g., 2 hours -> 1 hour -> 30 mins -> 15 mins) aiming for 100% accuracy!
