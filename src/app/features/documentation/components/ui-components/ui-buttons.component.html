Buttons

Buttons are implemented via the appButton directive, which can be applied to both HTML <button> and <a> anchor tags. It dynamically styles elements using semantic design tokens and manages loading and disabled states automatically.

Interactive Playground

Base Tailwind Classes

All button variants inherit the following core layout, typography, and interactive classes: 

group flex items-center justify-center gap-2 px-5 py-2.5 text-md font-medium cursor-pointer

Variant-Specific Tailwind Classes

Each variant appends specific styling classes to the base classes:

Variant Tailwind Classes Applied Description
primary bg-content text-main rounded-full Primary CTA with filled background and full rounded shape.
outline bg-surface rounded-full hover:bg-accent/10 Secondary button with border-base styling and hover tint.
danger bg-red-50 border-transparent rounded-full text-red-700 hover:bg-red-100 hover:text-red-800 transition-colors Soft red destructive button, darkening elements on hover.
ghost bg-transparent hover:bg-accent/10 border-transparent text-muted Minimal button with transparent background, showing accent tint on hover.

Disabled & Loading States Tailwind Classes

When [loading]="true" or [disabled]="true" is passed, the host element receives the following utility classes to prevent interaction and dim the component: 

pointer-events-none opacity-50

Usage Examples

1. Import ButtonComponent in your Angular component:

import { ButtonComponent } from '@shared/ui';

@Component({
  // ...
  imports: [ButtonComponent]
})

2. Use the directive in your component template:

<!-- Button element with primary variant -->
<button appButton variant="primary">Continue</button>

<!-- Anchor element styled as an outline button -->
<a appButton variant="outline" routerLink="/profile">View Profile</a>

<!-- Destructive action button with loading state -->
<button appButton variant="danger" [loading]="isDeleting" (click)="deleteItem()">
  Delete Account
</button>

Pure Tailwind Buttons

In cases where the appButton directive is not imported (such as standalone workspace widgets or sidebar forms), standard HTML button configurations are implemented using explicit Tailwind utility classes.

1. Primary Form Action Button

Commonly used as the primary submit button in sidebar modals, chapter creation panels, and tactics/drills setups.

Tailwind Classes Applied
w-full flex items-center justify-center gap-2 px-6 py-3.5 rounded-full bg-content text-white text-[16px] leading-5 font-medium cursor-pointer disabled:opacity-50 disabled:cursor-not-allowed
<!-- Pure Tailwind Primary Button -->
<button class="w-full flex items-center justify-center gap-2 px-6 py-3.5 rounded-full bg-content text-white text-[16px] leading-5 font-medium cursor-pointer disabled:opacity-50 disabled:cursor-not-allowed">
  Add Chapter
</button>

2. Icon / Toolbar Buttons

For specialized workspace toolbars (e.g., chess study board navigation controls), pure Tailwind circular icon buttons keep layouts compact and tightly aligned.

Tailwind Classes Applied
  • Base State: p-2 rounded-full transition-colors cursor-pointer hover:bg-subtle flex items-center justify-center text-content
  • Active State (e.g. Stop Session): text-rose-500 bg-rose-500/10
<!-- Pure Tailwind circular icon button -->
<button title="Flip Board" 
        class="p-2 rounded-full transition-colors cursor-pointer hover:bg-subtle flex items-center justify-center">
  <ng-icon name="heroArrowsRightLeft" class="text-lg"></ng-icon>
</button>
