User Account Management

Account registration flow

1 Frontend (Angular)

src\app\features\auth\register\register.html, src\app\features\auth\register\register.component.ts
  • Reactive Form Validation: Enforces data validation and complexity rules.
  • Reactive Submission Stream: Setting form inputs triggers a submissionPayload signal, firing an rxResource call.
  • Auth Service Interaction: Calls AuthService.register(payload) which makes a POST request to /api/register.
  • Token Storage: Saves plain-text Sanctum token under localStorage (key: chess_auth_token).
  • Routing & Redirection: Directs unverified users to /verify-email and verified users to /profile.
  • LinkedSignal Error Mapping: Error triggers an effect mapping failures to form-specific field signals via linkedSignal.

2 Backend (Laravel)

  • Duplicate Prevention: Explicitly queries the users table for duplicate emails/usernames before validation.
  • Request Validation: Validates fields matching complexity constraints and confirmation.
  • IP Country Detection: Employs DetectsCountry trait to query ipapi.co / ip-api.com for country detection.
  • Persistence & Model Instantiation: Instantiates and persists the following models in the database:
    • App\Models\User: Main user record representing the player credentials and registration data.
    • App\Models\UserPreference: Default customization settings (board style, sound theme, volume, etc.).
    • App\Models\UserProgress: Initial stats tracking model for the user's studies and puzzles.
    • Laravel\Sanctum\PersonalAccessToken: The authentication token issued to the client to authorize subsequent API requests.
  • Registered Event Notification: Dispatches the Registered event, triggering mailers to send the verification link.
  • Sanctum Issuance: Returns HTTP 201 Created with generated personal access token and user profile details.
