Service Downtime

August 3, 2026

Case study: On August 3, 2026, the website experienced database connection issues that caused pages to fail rendering, returning a generic Cloudflare Error 1102 (Worker Exception) or Not Found page to users.

The root cause was identified as a Supabase service issue: error: extension "pg_stat_statements" is not available. It was resolved by toggling the pg_stat_statements extension off and back on in the Supabase console. To address similar issues in the future, we implemented the mitigations documented below.

Worker-level fallback (SSR)

If our backend services or database are completely unreachable during your initial page load, Cloudflare Workers intercept the error and serve a lightweight, styled offline page. This page keeps you informed without throwing generic browser or Cloudflare exception codes. 

    
// _worker.ts / server.ts
try {{ '{' }}
  const response = await angularApp.handle(request);
  if (response && response.status >= 500) {{ '{' }}
    return getFallbackErrorPage();
  {{ '}' }}
  return response ?? new Response('Not Found', {{ '{' }} status: 404 {{ '}' }});
{{ '}' }} catch (err) {{ '{' }}
  console.error('SSR render failed:', err);
  return getFallbackErrorPage();
{{ '}' }}

Graceful client overlay

If database or backend connection issues arise while users are actively using the application, a full-screen overlay is displayed. This blocks interactions with broken interfaces. 

    
// http-error-interceptor.ts
